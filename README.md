# Fuelwise Android MVP

Single-user Android nutrition coach. No login, no Supabase.

## What works
- Local SQLite profile, meals, activity cache
- OpenAI key stored in Android secure storage
- Food logging from text
- Food photo estimation using OpenAI vision
- Context-aware AI coach using today's meals + goals + activity
- Android Health Connect permissions
- 30-day activity import
- Lean-gain calorie/macros baseline
- EAS config for installable APK
